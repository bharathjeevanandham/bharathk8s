UEK vs RHCK:

UEK (Unbreakable Enterprise Kernel): Oracle's custom, optimized kernel. Default in Oracle Linux 8+ for new installations. Offers newer kernel features and better performance for Oracle workloads.

RHCK (Red Hat Compatible Kernel): Binary-compatible kernel matching RHEL exactly. Required for certain applications certified only on RHEL.

RHEL Compatibility:
Oracle Linux is built from the same source packages as RHEL and is 100% binary-compatible. Minor release dates typically trail RHEL by 5–14 days.

Support Lifecycle:

Premier Support: Full support with bug fixes and security patches.

Extended Support: Security patches only, at higher cost.

Oracle Linux 7 moved to Extended Support on January 1, 2025.
